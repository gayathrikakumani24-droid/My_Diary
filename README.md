📔 My Diary – Personal Diary Web Application

->Overview
My Diary is a personal web application that allows users to securely record, view, and update their daily thoughts and experiences. The application focuses on privacy and simplicity, enabling users to maintain their own digital diary through authenticated access.
This project is designed to help users build a consistent habit of journaling while keeping their personal entries protected.

***Features***
Secure user authentication
Create, edit, and update diary entries
View previously written diary records
User-specific diary storage
Simple and clean interface
Data stored securely in a relational database

**Technologies Used**
Frontend
HTML
CSS
JavaScript
Backend
Node.js
Express.js
Database
SQL (MySQL)

**Authentication**
Each user has a unique account.
Only authenticated users can:
Access their diary
Create new entries
Update or edit existing entries
This ensures privacy and prevents unauthorized access.

***Purpose of the Project***
This project was developed to:
Understand full-stack web development
Implement user authentication securely
Practice database integration with backend services
Build a real-world application with CRUD operations

**Future Enhancements**
Password encryption using hashing
Diary entry search and filters
Mobile-responsive design
Cloud database integration
Reminder notifications for daily entries
